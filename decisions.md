# Wireframe Decisions Log

Working notes for the Utah County wedding venue wireframe. Edit freely — this file is the source of truth until the final spec is written.

Visual design rules come from [specs.md](specs.md): black and white only, one font, generic boxes, no imagery.

Data source: `Wedding Reception Project - Venues.csv` (46 venues, all kept).

## Site purpose
- A presentation of **wedding venues in Utah County**, built as a wireframe for usability testing.

## Global navigation (top bar)
| Item | Contents |
|---|---|
| Location | Dropdown of cities → list of venues in that city |
| Style | Dropdown: Rustic, Luxury, Modern, Outdoors, Classic → list of venues with that style |
| Explore | Goes to the base filter page |

## Landing page
- Scrolling carousel of links to pre-filtered pages:
  - Budget venues (price under $2k)
  - Spacious venues (capacity 200+)
  - Open catering (outside catering allowed)
- Each tile opens the Explore page with those filters pre-set.

## Explore page — local navigation (filters)
| Filter | Control | Options |
|---|---|---|
| Price | Range slider | $0 – $10k+ |
| Capacity (seated) | Range slider | 0 – 1000+ guests |
| Decor | Expandable section, checkboxes (match ALL) | "Included" / "For rent" toggles + sub-categories (see Decor items) |
| Parking | Checkbox | Designated lot |
| Style | Checkboxes (match ANY) | Rustic, Luxury, Modern, Outdoors, Classic |
| Audio/Visual | Expandable section, checkboxes (match ALL) | Microphone, TV, Sound system, Projector |
| Accessibility options | Expandable section, checkboxes (match ALL) | Wheelchair accessible, Elevator, ADA restrooms, Accessible parking |

## Decor items (from the CSV)
Each item can be matched as **Included**, **For rent**, or both (user checks one or both toggles; if neither is checked, both count). Included = listed in "Other Decor Included" or a no-cost extra; For rent = listed in "Other Decor for Rent" or a paid extra.

| Sub-category | Items |
|---|---|
| Specialty stations | Cake table, Sweetheart table, Drink / beverage station, Photo booth / backdrop, Firepit, Piano |
| Aesthetics | Ceremony arch / backdrop, Centerpieces, Greenery / florals, Signs / easels, Draping / chair covers, Fireplace |
| Lighting items | String / bistro lights, Chandeliers, Candles / lanterns |

## Data rules
- A venue can belong to **multiple styles**. Styles come from the **Description** column only, limited to Rustic, Luxury, Modern, Outdoors, Classic.
- **Price:** match if the venue's price range overlaps the slider range. Venues with no price show "Price not listed" and drop out once the slider moves off its default.
- **Capacity:** use the **maximum seated** number. Venues with no seated capacity show "Capacity not listed" and drop out once the slider moves. Standing capacity is shown on the venue page.
- **Yes/no checkboxes:** blank = no; only **included** counts as yes (a paid add-on does not match). The venue page still shows add-ons and their cost.
- **inside/outside "Both"** → matches both Indoors and Outdoors checkboxes.
- **Missing cities:** inferred from the description where it names a city; the rest are supplied by the user.

## Decisions (Q&A)
1. **Leaves = individual venue pages.** Filters and navigation narrow a list of venues; clicking a venue shows its endpoint page.
2. **Venue data comes from the CSV.** All 46 rows kept, including the out-of-county ones and Sun River Gardens.
3. **Global nav Location/Style = dropdown menus.** Choosing a city or style opens a list page of matching venues (e.g., Style → Rustic → Venue).
4. **Explore Style filter = checkboxes, match ANY.** Checking Rustic + Modern shows venues tagged Rustic OR Modern.
5. **Decor, Audio/Visual, and Accessibility = expandable (accordion) sections with checkboxes, match ALL.** Checking Microphone + Projector shows venues that have both.
6. **Decor items are sub-categories** (Specialty stations, Aesthetics, Lighting items) holding specific items, with **Included** and **For rent** toggles the user can check one or both of.
7. **Parking = "Designated lot" checkbox only.** Stall-count slider dropped (only 6 venues list a count).
8. **Slider ranges:** Price $0 – $10k+ (top end means "$10k and up"); Capacity 0 – 1000+ guests (top end means "1000 and up").
9. **Carousel tiles open the Explore page with filters pre-set** (user can keep refining):
   - Budget venues → price under $2k
   - Spacious venues → capacity 200+
   - Open catering → "Outside catering allowed" checked
10. **Build click recording and test mode.** Every click is logged with JSON/CSV export. Test mode: show scenario → participant clicks OK → timer starts → clicks recorded → reaching a venue page records the endpoint → next task. All 10 scenarios run in random order, and results persist in the browser for later review. Scenarios are in wireframe-spec.md.
11. **Explore results update live** as filters change, with a "Showing N venues" count.
12. **Missing cities:** inferred from description where possible; user supplies the rest.
13. **Price filter:** range overlap; unpriced venues hidden once the slider moves.
14. **Capacity filter:** max seated capacity; blank venues hidden once the slider moves. Standing capacity shown on the venue page.
15. **Checkbox filters:** blank = no; only included services count (paid add-ons don't match).
16. **"Wheelchair accessible" → "Accessibility options"** section covering all accessibility data: Wheelchair accessible (incl. "Handicap accessible"), Elevator, ADA restrooms (incl. "ADA-accessible bathrooms"), Accessible parking.
17. **Venue endpoint page:** summary box (name, city, description, price, seated + standing capacity, styles, key attributes), plus an expandable "All details" section with every CSV field, organized into groups and hiding empty fields.
18. **Outdoors style = nature-centered setting** (farms, gardens, ranches, ponds, greenhouses, golf grounds). The Outdoors checkbox separately means "has outdoor space".
19. **"Elegant" venues are tagged Classic** unless they are super fancy (country club, castle, resort, hotel, full-service, destination estate), which are Luxury.
20. **Cities supplied:** Orion → Lindon, Hobble Creek → Springville, TalonsCove → Saratoga Springs, River Bridge → Spanish Fork.
21. **Barteli Event Venue = Classic.**
22. **Decor items derived from the CSV** (see Decor items table).
23. **No more carousel tiles** for now (Budget, Spacious, Open catering only).
24. **Tree test mode follows the course Tree Test spec** (participant ID, shuffled tasks per participant, "I would give up" button, `?test` and `?results` URLs). Full details and the 10 scenarios are in wireframe-spec.md.
